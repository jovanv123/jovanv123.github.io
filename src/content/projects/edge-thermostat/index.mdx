## Problem

People adjust their thermostat by hand all day. The goal was a device that learns those preferences and sets the temperature itself, running entirely on a low-cost microcontroller.

## Architecture

Built on a Waveshare ESP32-S3 board with a 4" touchscreen. The firmware runs four FreeRTOS tasks: the LVGL interface (every 20 ms), mode logic with Wi-Fi weather data and neural-network inference (1 s), heating control (1 s) and a stack/memory monitor (5 s).

- **Auto**: A quantized 2-16-8-1 neural network predicts the comfort temperature from outdoor temperature and hour.
- **Manual**: The user sets the temperature on a touch slider. Each change becomes training data.
- **Away**: Follows the outdoor temperature, clipped to 19–26 °C, to save energy.

Every manual change is logged as a ground-truth sample. Once enough new samples accumulate, a Python script retrains the network on the extended dataset, and the device loads the updated model on its next boot, simulating an over-the-air update.
