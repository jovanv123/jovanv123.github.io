## My contribution

- **The low-level control stack, written from scratch, and its integration with the
  perception layer.** All STM32H7 firmware in C: 1 kHz PID and encoder odometry,
  trapezoidal motion profiles, actuator drivers and the behaviour state machines,
  connected over UART to the ROS 2 high-level layer on the Raspberry Pi 5 that runs
  ArUco-based perception and match strategy.
- Software lead: the software architecture across both robots.
- Previous season: trained the game-element recognition model for dynamic strategy.
