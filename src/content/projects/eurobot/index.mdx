## Problem

Eurobot is an autonomous robotics competition: robots score points on a
3000 × 2000 mm field in a 100-second match, with no human input and an
opponent moving on the same table. That demands reliable motion, safe
obstacle handling and a strategy that adapts to what is actually on the
field.

## Low-level control stack · 2026

I wrote the entire embedded stack from scratch in C on an STM32H7, with no
vendor motion libraries: PID control with encoder odometry, trapezoidal velocity profiles, drivers for servos, steppers and
sensors, and concurrent state machines that run navigation and mechanisms
in parallel. It connects over UART to a ROS 2 high-level layer on a
Raspberry Pi 5, which handles ArUco-based perception and match strategy.

## Vision from synthetic data · 2025 (published)

Labelled real images of the field were scarce, so we built a
photorealistic Eurobot field in Unreal Engine 5 that procedurally
randomizes object poses, lighting, camera position and materials, and
exports every render with YOLO labels. Moving from pure synthetic data to
a hybrid set (~780 synthetic + ~150 real images) closed most of the
sim-to-real gap. The YOLOv11 detector was served to the robot over Wi-Fi
as a live map of which game elements were still available.
